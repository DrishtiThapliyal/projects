# CAPTCHA + OTP Login System

A simple web-based secure login system featuring CAPTCHA verification and OTP (One-Time Password) authentication.

## Features

- **CAPTCHA Generation**: Random 5-character alphanumeric CAPTCHA
- **CAPTCHA Verification**: User input validation with attempt limits
- **OTP Generation**: 6-digit OTP with 2-minute expiry timer
- **OTP Verification**: Secure OTP input with attempt tracking
- **Responsive Design**: Clean, modern UI with dark theme

## How to Run

1. Clone the repository
2. Open `index.html` in a web browser, or
3. Serve the files using a local web server (e.g., `python -m http.server`)

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
